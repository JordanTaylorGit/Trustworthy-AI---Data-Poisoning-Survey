# AI Use Log

| Date | Who | Tool (and version) | Used for | How verified / revised |
|---|---|---|---|---|
| | | | e.g. initial project plan and candidate paper list | e.g. checked every title, author, venue against publisher page; replaced X |
| | | | e.g. site scaffold (HTML/CSS/JS) | e.g. ran locally, edited layout and copy |
